# Notes
Simple notes app writen in C++

## Commands 


| name | description 
|--|--|
| `list` | get all notes
| `upload` | save note in file
| `change` | change note text
| `get` | get note by name
| `remove` | remove note
| `rename` | rename note
| `q` | quit
| `help` | get all commands
| `count` | count all notes
| `append` | append text to note
| `random` | get random note 
| `duplicate` |duplicate note 



## Build
Build the app using CMake 

```text
Press `F7`
```
## Run
Run the app 
```bash
./app
```
