# Notes
Simple notes app writen in C++

## Commands 


| name | description 
|--|--|
| `list` | get all notes
| `upload` | save note in file
| `change` | change note text
| `get` | get note by name

## Build
Build the app using g++ compiler

```bash
g++ notes.cpp -o app
```
